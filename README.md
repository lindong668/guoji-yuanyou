## 二、★ 与 3 号的依赖关系（3 号要不要改？）

### 结论：**3 号不用改。**

| 数据 | 来源 | 靠 3 号吗 |
|---|---|---|
| 布伦特 / WTI 实时价 | `/api/oil-live` — 8 源链路 | **主要不靠**，`site3` 只是兜底之一 |
| 黄金实时价 | 前端 4 源 + `/api/gold-live` 7 源 | **主要不靠**，3 号是兜底 |
| **国内油价（各省 92/95/98）** | `getMarket()` → 3 号 `/data` 带 `X-Access-Key` | **必须靠 3 号** |
| 汇率换算 | `open.er-api.com` 主 + `frankfurter.dev` 备 | **完全不靠 3 号** |

### 为什么 3 号不用改

1. `/data` 接口结构没变，2 号仍以同样方式（带 `X-Access-Key`）读取
2. 密钥与 3 号一致，未改动
3. 新增的兜底调用只在**主源全挂时**才轮到 3 号，负载可忽略

### ⚠️ 但有一件事要盯

国内油价是 **3 号 cron 定时抓**（每天 08:30 Asia/Shanghai）。
如果 3 号的定时任务挂了或额度耗尽，国内油价会显示旧值且**页面不会报错**。
所以 3 号仍需保持正常运行 —— 它现在是国内油价的**唯一来源**。

## 二之一·补、★ 法语首页标题被劈成"四行"（本次再修）

上一轮修复引入的新问题：法语首页卡片标题被拆成三四行，非常难看。

```
根因一：.ttl 写了 overflow-wrap:break-word —— 允许在【单词内部】断开。
        法语 "Pétrole brut Brent" 被劈成 Pétro / le / Brent …，行数暴涨。

根因二：首页徽标用的是完整文案，法语
        "En direct · Mis à jour il y a 14s" 有 30+ 字符，
        与 19 字符的长标题挤在窄卡片里必然换行。

修法：
  .card h3 .ttl   overflow-wrap:normal + word-break:normal
                  → 只在【词与词之间】换行，单词保持完整，最多折两行
  .card h3 .ttl   flex:0 1 auto（不强制伸展，可收缩吸收剩余变化）
  首页徽标         改为【精简文案】：「实时 · 14s」
                  去掉 "Mis à jour il y a" 这类前后缀，长度砍掉一半以上
  详情页           空间宽裕，仍用完整文案（不改）

domtest 实测首页徽标渲染结果：
  修复前  [En direct · Mis à jour il y a 0s]
  修复后  [En direct · 0s]

⚠️ 局限：jsdom 不做布局计算，"几行"必须浏览器目测确认。

## 二之二、★ 徽标随秒数上下跳（本次修复）

现象（法语首页 + 浏览器翻译为中文时最明显）：

```
秒数是个位数 → 徽标在标题右边
秒数变两位数 → 徽标整块掉到下一行
```

```
根因：上一轮为解决"长语言徽标被挤掉"，给 .card h3 加了 flex-wrap:wrap。
      徽标宽度会随位数变化（4s→14s 多一个字符），
      宽度刚好跨过阈值时就被挤到第二行 —— 于是随着秒数跳动反复上下跳。

修法（不再让徽标换行，改为让【标题】吸收宽度变化）：
      .card h3        flex-wrap:nowrap   整行永不换行，徽标始终留在标题同一行
      .card h3 .ttl   flex:1 1 auto + overflow-wrap:break-word
                      标题包进 .ttl，空间不够时由它收缩/内部换行
      .live-dot .ago  min-width:3ch
                      锁住最长形态（14s / 59s / 10m 都是 3ch），
                      一位变两位时徽标宽度不变 → 标题不用重排 → 卡片高度不跳

代价：一位数时秒数右侧最多多留约 1 个字符（0.7rem 下 ≈6px），
远小于之前 3.2ch 留白 + 双重 flex gap 造成的那种明显"分开"。

⚠️ 顺带修了一个测试假阳性：CSS 断言没剥注释，
   注释里写的"之前用 flex-wrap:wrap"被正则命中，
   规则已改成 nowrap 测试却仍报通过。现在所有 CSS 断言先 stripCss() 再匹配。

⚠️ 局限：jsdom 不做布局计算，"不再跳行"需在浏览器目测确认
   （法语首页开浏览器翻译，盯 10 秒以上）。
```

## 三、怎么部署

```bash
npx wrangler deploy
```

### 关于 3 号密钥

当前走**内置默认值**（与 `data.js` 里 `SOURCE_ACCESS_KEY` 同样处理），开箱即用。
若日后要挪到 secret，需改 `oilLive.js` / `goldLive.js` 两处从 `env` 读取
